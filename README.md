# 🚀 PathPilot AI

AI-powered Career Intelligence Platform built using Flask.

## Features

- Resume Parsing & Skill Extraction
- Skill Score & Readiness Score
- AI Career Roadmap Generator
- Job Match Engine
- Salary Prediction Engine
- Market Intelligence Dashboard
- Application Tracker
- Admin Dashboard
- Forecasting Module

## Tech Stack

Backend:
- Flask
- SQLAlchemy
- SQLite
- Jinja2

Frontend:
- Bootstrap 5
- Vanilla JS

## Architecture

Modular Flask architecture:
- routes/
- services/
- models/
- utils/
